# Personal-Finance-Dashboard-excel# 📊 Personal Finance Dashboard (Advanced Excel)

## 📌 Project Overview
This project focuses on building a personal finance tracker to manage income, expenses, and savings. The objective is to clean transaction data, track cash flow metrics, and visualize monthly spending trends to enable better financial planning and decision-making.

## 🛠️ Tech Stack & Advanced Excel Skills Used
*   **Data Cleaning & ETL:** Power Query (Ingesting transactional logs, fixing missing values, categorization).
*   **Data Modeling & Analysis:** Pivot Tables, Pivot Charts, Formulas (`SUMIF`, `AVERAGEIF`, Date Functions).
*   **Interactive Visualization:** Dynamic Charts, KPI Cards, and Timeline Slicers for historical trend mapping.

---

## 🔍 Key Insights & Financial Problems Solved

### 1. Cash Flow Tracking
*   Developed high-level KPI cards tracking total Credit (Income), Debit (Expenses), Net Balance, and total transaction volume.
*   Established a clear baseline for monthly savings metrics.

### 2. Category-Wise Expense Distribution
*   Aggregated and mapped daily transactions into distinct spending categories (e.g., Food, Utilities, Entertainment, Investment).
*   Identified major cost-drivers and areas of financial leakage.

### 3. Historical Spending Trends
*   Created interactive timeline filters to easily analyze month-on-month expense variations and financial behaviors.

---

## 📈 Actionable Takeaways
1. **Budget Management:** Transformed messy transaction logs into a clean, automated dashboard that replaces manual expense tracking with a real-time visual summary.
2. **Data-Driven Savings:** Provided a clear view of the net savings rate, helping users easily identify which categories can be optimized to reach financial goals faster.
